# Backend

This folder will contain the Python API and assessment workflow.

Planned responsibilities:

- Validate assessment requests.
- Maintain the internal governance requirement catalog.
- Coordinate AI analysis and validate structured results.
- Return evidence-linked findings to the React frontend.

The Python application and its dependencies have not been initialized yet. Keep backend dependencies and configuration in this folder. Use a local `.venv/` for Python dependencies and an ignored `.env` for credentials. Commit only placeholder values in any future `.env.example`.
